# MariaDB Server Home Assistant App

This is a focused fork of the official Home Assistant MariaDB app, adapted for
MariaDB Server from Debian packages.

The app is intended for Home Assistant recorder migrations that need a MariaDB
target compatible with a Debian MariaDB source.

## App

- Name: MariaDB Server
- Slug: `mariadb_server`
- Image: `ghcr.io/wheemer/amd64-app-mariadb-server`
- Supported architecture: `amd64`
